# My ITE TUTORIAL

## Purpose
This repository was created for ITE 1100 Tutorial #4 (Parts A and B) to practise
a basic Git and GitHub collaboration workflow: creating a repository, branching,
committing, opening a Pull Request, getting it reviewed, and merging.

## Collaborators
- Kofi Hossannah (GitHub: kofi20i), repository owner
- Sean Griffith (GitHub: Seanyyy1), collaborator and Pull Request reviewer

## Steps followed
1. Installed GitHub Desktop and signed in to GitHub.
2. Created the repository `My-ITE-TUTORIAL` and published it as a public repository.
3. Added Sean Griffith as a collaborator.
4. Created a new branch called `Add-Files`.
5. Added a new file, `Information-Technology.py.txt`, that prints my name and "HELLO WORLD".
6. Committed the file to the `Add-Files` branch.
7. Pushed (published) the branch to GitHub.
8. Opened Pull Request #1 and requested Sean as the reviewer.
9. Sean reviewed and approved the Pull Request.
10. Merged `Add-Files` into `main`.
